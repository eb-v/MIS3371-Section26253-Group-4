Check out a book

Prepare a checkout request for one library book.

Checkout details

Enter the reader ID and scan the book barcode or enter its ISBN. Select the requested checkout date. The loan period is five calendar days; the completed system will calculate the due date automatically. Add notes if needed.

Page prototype: This form does not submit or save a checkout. Due-date calculation and library record checks will be added in a later milestone.

Fields marked (required) must be completed for a checkout request.

Calculated as checkout date plus five calendar days when checkout logic is connected.

Before a checkout is approved

  • The barcode or ISBN must match an existing book record.
  • The book must be available and have no active hold for another reader.
  • The reader's fines must not exceed the library's allowed limit.
  • The checkout must not exceed the reader's maximum item limit.
  • Only one reader may check out a physical book at a time.

An approved checkout will receive a checkout ID and change the book status from Available to Checked Out. A rejected request will display the reason.
